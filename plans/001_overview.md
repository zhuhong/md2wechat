# md2wechat 产品需求文档

## 1. 产品定位

一个基于网页的 Markdown 编辑器，专门用于将 Markdown 内容渲染成微信公众号文章排版。

## 2. 核心功能（对标 md.doocs.org）

### 2.0 实施边界
- **第一优先级**：本地优先的 Markdown -> 微信公众号兼容 HTML 编辑器。
- **第二优先级**：图片上传/图床、草稿管理、主题编辑等增强能力。
- **第三优先级**：飞书/Notion/微信公众号 API，需要后端代理、鉴权和资源搬运，不能按纯前端功能估算。

### 2.1 编辑与预览
- 左栏编辑、右栏预览的双栏实时布局
- 首版先支持单文档编辑，多标签页放到 v0.4
- 编辑器支持 Markdown 语法高亮、查找替换、常用快捷键

### 2.2 文件操作
- 新建文档
- 打开本地 .md 文件
- 保存为 .md 文件
- 自动保存草稿到本地存储（IndexedDB）
- 导出为 HTML

### 2.3 Markdown 扩展支持
- 标准 GFM（表格、任务列表、删除线等）
- KaTeX 数学公式
- Mermaid 流程图/时序图/类图
- PlantUML 图表
- 脚注（Footnotes）
- GFM 警告框（Alerts: NOTE, TIP, WARNING, CAUTION, IMPORTANT）
- 目录（TOC）自动生成
- 上标/下标
- 高亮标记

### 2.4 主题与样式
- 多款预设微信公众号风格主题
- 主题切换实时预览
- 自定义主题导入（CSS / JSON）
- 字体、颜色、间距、边框可调

### 2.5 代码高亮
- 支持 180+ 编程语言
- 行号显示（可选）
- 代码块复制按钮

### 2.6 发布与导出
- 一键复制微信兼容 HTML 到剪贴板
- 下载为 HTML 文件
- 图表导出为 SVG / PNG
- 图片上传到图床或公众号素材库（未来扩展）
- 微信草稿箱发布（未来扩展，需要后端保存 appid/secret 或用户授权）

### 2.7 外部文档导入（差异化功能）
- **本地导入优先**：支持粘贴 Markdown、打开 `.md`、导入 Notion/飞书手动导出的 Markdown/HTML 压缩包。
- **飞书云文档导入**：输入飞书文档 URL，通过后端调用飞书 docx 块 API，再转换为 Markdown/HTML。
- **Notion 页面导入**：输入 Notion Page URL，通过后端调用 Notion Markdown Content API 获取 Enhanced Markdown。
- 导入后需要统一做图片资源搬运：下载临时资源 -> 上传到图床/公众号素材库 -> 替换正文 URL。

### 2.8 AI 辅助（预留扩展点）
- MCP Server 接口，供 AI Agent 调用
- AI 润色、排版优化（未来扩展）

## 3. 目标用户
- 技术公众号作者
- 内容创作者
- 需要频繁在飞书/Notion 写稿后转公众号的团队

## 4. 使用流程

```
1. 打开网页 -> 看到默认欢迎文档
2. 方式 A: 直接在左侧编辑 Markdown
   方式 B: 点击"导入" -> 选择飞书/Notion -> 粘贴 URL -> 获取内容
3. 实时在右侧预览渲染效果
4. 切换主题，调整样式至满意
5. 点击"复制" -> 粘贴到微信公众号编辑器
6. （可选）点击"发布" -> 直接推送到公众号草稿箱
```

## 5. 兼容性目标
- 现代浏览器：Chrome, Edge, Firefox, Safari
- 移动端浏览器：可查看预览，编辑体验以桌面为主
