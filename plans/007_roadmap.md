# 实施路线图

## 阶段一：MVP（核心功能，预计 2-3 天）

**目标**：基础双栏编辑器 + markdown-it 渲染 + 微信兼容 + 复制功能

| 任务 | 说明 | 预估 |
|------|------|------|
| 1.1 初始化项目 | pnpm workspace + Vite + React + TS + Tailwind + shadcn/ui | 2h |
| 1.2 搭建双栏布局 | SplitPane 可拖拽分栏 | 2h |
| 1.3 集成 CodeMirror 6 | 基础编辑功能 + Markdown 语法高亮 | 1h |
| 1.4 集成 markdown-it | 基础 GFM 渲染（标题/列表/链接/图片/表格/代码） | 2h |
| 1.5 微信兼容后处理 | 主题 token -> inline style、剪贴板 HTML 输出、图片状态提示 | 3h |
| 1.6 复制到剪贴板 | Clipboard API + execCommand fallback | 1h |
| 1.7 2 个基础主题 | 默认主题 + 极简主题 | 2h |
| 1.8 顶部工具栏 | 文件/编辑/复制按钮 | 2h |
| 1.9 中文排版优化 | 标点挤压、中英文间距 | 1h |
| 1.10 复制验收样例 | 用固定 Markdown 样例验证公众号粘贴效果 | 1h |
| **合计** | | **17h** |

**验收标准**：
- ✅ 可以编写 Markdown，实时预览
- ✅ 复制后粘贴到微信公众号编辑器格式正确
- ✅ 支持标题、列表、链接、图片、表格、代码块
- ✅ 复制 HTML 不包含应用按钮、调试节点或预览容器
- ✅ 外链图片有清晰风险提示

## 立即开始的下一步

如果你准备好开始，建议的顺序是：

1. **初始化项目骨架**（阶段一 1.1）
2. **搭好双栏布局**（阶段一 1.2）
3. **接入 CodeMirror + markdown-it**（阶段一 1.3-1.4）
4. **实现微信兼容+复制**（阶段一 1.5-1.6）

这 4 步完成后，你已经拥有一个可用的最小可用产品，可以立即用来写公众号文章。

后续功能可以按需逐步叠加。
